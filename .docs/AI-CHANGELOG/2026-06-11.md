## 1. การแก้ไขปัญหา FastAPI Event Loop Blocking (Model DoS / Performance Loophole)
* **Unblocking CPU-bound Endpoints:** เปลี่ยน endpoint `optimize_route` ใน `optimize.py` และ `rank_dispatch_candidates` ใน `dispatch.py` จาก `async def` เป็น sync `def`
* **FastAPI Thread Pool Routing:** ช่วยให้ FastAPI ส่งงานคำนวณหนักของ Google OR-Tools และ Haversine Distance Matrix ไปรันใน Thread Pool เบื้องหลัง ทำให้ Event Loop ของ uvicorn ไม่ถูกบล็อก
* **Container Rebuild:** ทำการ build คอนเทนเนอร์ `delivery-ai` ใหม่เพื่อให้ทำงานด้วยโค้ดปัจจุบันในระบบ Docker
* **Proof of Concept:** ทดสอบยิง VRP optimization ที่มี 60 จุดควบคู่กับการยิง Health check `/health` พบว่า `/health` ตอบกลับ 200 OK ทันทีเฉลี่ยภายใน 0.02 วินาที โดยไม่เกิดการค้างสะสม

## 2. การปิดช่องโหว่ DOM-based XSS & Script Injection บน Map Popups
* **HTML Sanitization:** สร้างและนำฟังก์ชัน `escapeHtml()` มาช่วยจัดระเบียบและ escape dynamic variables ทั้งหมด (เช่น `riderId`, `status`, `label`, `phone`, `name`, `menuName`) ก่อนนำไปทำ String Interpolation ลงใน Leaflet popup HTML
* **Leaflet Programmatic Event Binding:** ลบ inline `onclick` string binding ออกทั้งหมด (เช่นการดึง reference ผ่าน global scope window) เปลี่ยนไปใช้ dynamic event listeners (`addEventListener`) ที่ผูกบนอีเวนต์ `popupopen` ของ Leaflet marker โดยตรงผ่าน DOM query selector
* **Global Scope Attack Surface Reduction:** ถอนโค้ดบริดจ์ `window.angularComponentReference` ออกทั้งหมดเพื่อป้องกันช่องโหว่การทะลวงผ่าน Client-side Scripting
