## 1. ยกระดับลอจิกธุรกิจ (Business Logic & Dispatch Flow)

* **OSRM 4-Point TSP:** แก้ไขสมการเส้นทางงานพ่วง (Batch) จาก 3 จุดเป็น 4 จุด (รวมจุดรับออเดอร์ที่ 2) ทำให้ระบบจัดลำดับการส่งได้ฉลาดขึ้น ไรเดอร์ไม่ขับรถวนไปมา
* **Cumulative Batch ETA:** เปลี่ยนวิธีคำนวณ ETA ของงานพ่วงให้เป็นแบบ "สะสมเวลา (Sequential)" พร้อมบวกเวลาทำรายการ 180 วินาที ทำให้ลูกค้าได้เวลาประเมินที่แม่นยำที่สุด
* **Dynamic Injection Clean-up:** ป้องกันฐานข้อมูลพัง (Data Corruption) โดยการสั่งเคลียร์ `BatchGroupId` ทันทีเมื่อไรเดอร์ปฏิเสธงานแทรก ป้องกันเคสผีหลอก (1 ออเดอร์ 2 ไรเดอร์)

## 2. ยกระดับความทนทานของระบบ (System Resilience & Fail-Safe)

* **Redis Rate Limiter (Fail-Open):** ใส่ try-catch ให้ระบบจำกัดทราฟฟิก หาก Redis ล่ม ระบบจะยอมปล่อยพิกัด GPS ไรเดอร์ผ่านไปก่อน (ไม่บล็อก) เพื่อประคอง Core Feature ให้ทำงานต่อได้
* **OSRM JSON Fallback:** ดักจับ Exception กรณี OSRM ส่งข้อมูลขยะกลับมา โดยให้ระบบสลับไปใช้เส้นทางแบบเรียงลำดับเบื้องต้นแทนการปล่อยให้แอปพลิเคชันแครช (Graceful Degradation)
* **OsrmSnapWorker Fail-Fast:** ป้องกันการเกิดซอมบี้โปรเซส (Zombie Process) โดยการดักจับ exception ระหว่างเริ่มการเชื่อมต่อกับ RabbitMQ แล้วสั่งดับโฮสต์ด้วย `StopApplication()` เพื่อให้ container orchestrator ดึงใหม่อย่างรวดเร็ว

## 3. ยกระดับความปลอดภัย (Enterprise Security & DoS Protection)

* **Zero-Trust TrackingHub:** ปิดตาย Backdoor! ลบโค้ดที่ยอมให้ Localhost (127.0.0.1) ทะลวงเข้ามารับสิทธิ์ Admin ออกไป ทุกการเชื่อมต่อต้องมี JWT Token เท่านั้น
* **GPS Sliding Window:** กางโล่ป้องกัน DoS Attack โดยตัดทิ้งพิกัด GPS ที่เก่าเกิน 15 นาที หรือล้ำอนาคตเกิน 1 นาที ป้องกัน Database บวมและพัง
* **AI Boundary Validation:** ใส่เกราะป้องกันให้ `vrp_solver.py` ดักตรวจสอบค่าดัชนี (Index) ก่อนส่งให้ OR-Tools ป้องกันไม่ให้ C++ โยน Exception ทำคอนเทนเนอร์ล่ม
* **Chat History Limit & Age Gates:** จำกัดการเรียกดูประวัติแชทเฉพาะออเดอร์ที่ไม่เกิน 7 วัน และทำการดึงข้อมูลสูงสุด 50 ข้อความล่าสุดในรูปแบบ Chronological Order พร้อมกางโล่ DoS ป้องกัน Payload ขนาดใหญ่โดยจำกัดความยาวของข้อความไว้สูงสุดที่ 1,000 ตัวอักษร
* **Chat Hub SQL Query Spam Fix:** แคช `RiderId` ใน `Context.Items` ขณะที่เชื่อมต่อ SignalR และสกัด `shop_id` โดยตรงจาก JWT claims สำหรับ `StorePartner` ลดภาระคิวรีฐานข้อมูลโดยไม่จำเป็นในทุกๆ ข้อความที่ส่งเข้า Hub

## 4. จัดการหนี้สินทางเทคนิค (Tech Debt & Code Quality)

* **Culture-Invariant Cache Keys:** บังคับคีย์ Redis ให้ใช้จุดทศนิยม (.) เสมอ ปิดตำนานบั๊กลูกน้ำ (,) เวลาเอาไปรันบนเซิร์ฟเวอร์โซนยุโรป
* **No More Magic Strings:** รื้อระบบ State Handler เปลี่ยนจากข้อความ String ลอยๆ ("IDLE", "RECOVER") ไปใช้ Enum ที่ Type-safe 100%
* **Structured Logging:** บังคับยัด `OrderId` และ `RiderId` ลงไปใน Serilog Context ตามมาตรฐาน `AGENTS.md` เป๊ะๆ
