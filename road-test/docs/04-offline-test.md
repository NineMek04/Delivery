# 04 — Offline GPS Buffer & Reconnection Test

## วัตถุประสงค์
ทดสอบการทำงานของ SQLite Local Buffer เมื่อโทรศัพท์หลุดการเชื่อมต่ออินเทอร์เน็ต (เช่น เข้าจุดอับสัญญาณหรือเน็ตมือถือหลุด) และทดสอบการอัปโหลดแบบ Batch เมื่ออินเทอร์เน็ตกลับมา

---

## ขั้นตอนการทดสอบ

1. **เริ่มต้นการติดตามพิกัด:**
   * เปิดแอป Rider และเริ่มบันทึกตำแหน่งตามปกติ

2. **จำลองเน็ตหลุด (Disconnect):**
   * ปิด Cellular Data (4G/5G) และ Wi-Fi บนโทรศัพท์มือถือ
   * เคลื่อนที่ต่อไปเป็นระยะทางประมาณ 200 – 300 เมตร
   * ตรวจสอบว่าพิกัด GPS ยังคงถูกบันทึกลงในฐานข้อมูล SQLite ภายในเครื่องอย่างต่อเนื่อง

3. **กู้คืนการเชื่อมต่อ (Reconnect):**
   * เปิด Cellular Data (4G/5G) บนโทรศัพท์อีกครั้ง
   * สังเกตการทำงานของ `GpsBufferService`:
     * แอปพลิเคชันต้องส่งพิกัดที่ค้างอยู่ในเครื่องผ่าน `POST /api/v1/telemetry/gps/batch` โดยอัตโนมัติ
     * SignalR ต้องเชื่อมต่อกลับเข้ามาใหม่ (Auto-Reconnect)

4. **ตรวจสอบความสมบูรณ์ของข้อมูล:**
   * เช็คบน Database PostGIS ว่าพิกัดช่วงที่เน็ตหลุดถูกเติมเต็มเข้าสู่ประวัติเส้นทางอย่างครบถ้วนโดยไม่มีจุดตกหล่น
