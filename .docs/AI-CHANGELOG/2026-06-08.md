- **Action:** แก้ไข `AuthService.cs` (`LoginAsync`) ดักปฏิเสธคำขอก่อนเทียบรหัสผ่าน (VerifyPassword) และบันทึก Log เหตุการณ์ความปลอดภัย ได้แก่ `ACCOUNT_LOCKED`, `ACCOUNT_LOCKOUT_ATTEMPT`, และ `ACCOUNT_UNLOCKED` ตามโครงสร้าง Trace Correlation

- **Action:** ปรับไปใช้ระบบ Lockout Key สองระดับ: `login:user:{userId}` สำหรับผู้ใช้ที่มีอยู่จริง และ `login:email:{normalizedEmail}` สำหรับผู้ใช้ที่ไม่มีในระบบ เพื่อป้องกัน brute-force ตรวจจับการเดา username
