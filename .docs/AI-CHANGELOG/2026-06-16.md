# [Dev Team] Changelog: 2026-06-16

สรุปการเปลี่ยนแปลงที่ commit ในวันที่ 16 มิถุนายน 2026

## 1. OSRM Route-based Simulation & Rider Map Drawing Hardening

### Backend API (.NET 8)
- **Delete Customer History Endpoint:** เพิ่มเมธอด `ClearCustomerOrdersAsync` ใน `IOrderService` และ `OrderService` สำหรับทำ Soft Delete (`IsDeleted` / `DelFlag = 'Y'`) ออเดอร์ทั้งหมดของลูกค้าเพื่อความปลอดภัยและเก็บ Audit Logs และเพิ่ม endpoint `DELETE /api/v1/orders/customer/clear` ใน `OrdersController`

### Flutter App (Rider & Customer Multi-Role)
- **OSRM Dynamic Routing & Drawing:**
  - อัปเดต `route_tracking_screen.dart` ให้เรียกใช้ `riderRouteApiServiceProvider.resolve` เพื่อดึงพิกัดเส้นทางถนนจริงจาก OSRM เสมอ (ทั้งฝั่งจุดรับของ `PICKUP` และจัดส่ง `DELIVERY`)
  - วาดเส้นทางจริงลงบนแผนที่ด้วย `PolylineLayer` และทำการตัดปลายพิกัดที่วิ่งผ่านมาแล้วแบบเรียลไทม์ด้วย `_getTailRoute`
- **Remaining Road Distance Calculation:**
  - ปรับปรุงการคำนวณระยะทางจากพิกัดกระจัด (Displacement Straight Line) เป็นการหาผลรวมของความยาวเซกเมนต์โครงข่ายพิกัดจริง OSRM ใน `simulated_journey_service.dart` เพื่อความแม่นยำตรงตามสภาพพื้นที่จริง
- **Navigation Redirection:**
  - อัปเดต `app_router.dart` ให้ลงทะเบียน `/delivery/tracking/:orderId` (`RouteTrackingScreen`) เป็นซับเร้าท์หลัก เพื่อป้องกันการสลับแท็บหลุดของเนวิเกชั่น
  - แก้ไข `home_screen.dart` และ `active_delivery_screen.dart` ให้เชื่อมต่อไปยังหน้าจำลองการวิ่งของพิกัด OSRM จริงของออเดอร์นั้นๆ โดยตรงเมื่อมีการทำงานออเดอร์ปัจจุบัน
- **Direct Checkout Buy Now (Cart Bypass):**
  - เพิ่มปุ่ม "ซื้อทันที" ในหน้าจอรายละเอียดร้านค้า `shop_details_screen.dart`
  - หากเมนูมีตัวเลือกเพิ่มเติมจะแสดง `DishOptionsBottomSheet` โดยใช้ธง `isBuyNow: true` เพื่อล้างตะกร้าสินค้าเก่าออกแล้วเพิ่มสินค้านี้เข้าไปเดี่ยวๆ และเปิดหน้าแสดงสรุปราคาและยืนยันการสั่งซื้อ `CartBottomSheet` ทันที ข้ามขั้นตอนยุ่งยากลงตะกร้าแบบเดิม
- **Clear Order History Action:**
  - เพิ่มปุ่มถังขยะ `delete_sweep` ด้านบนสุดของ `customer_orders_screen.dart` พร้อมกล่องหน้าต่างยืนยันการล้างประวัติ (Confirmation Dialog) เพื่อเรียก API `clearCustomerOrders` และล้างรายการหน้าบ้านออกทันที
