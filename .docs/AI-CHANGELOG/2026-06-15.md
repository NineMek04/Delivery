* **Data Consistency:** ปรับปรุง [ShopsController.cs](file:///c:/Users/ASUS/Desktop/Project/Delivery/BackendApi/Controllers/MasterData/ShopsController.cs) โดยการย้ายคำสั่งการส่งบรอดแคสต์ SignalR อีเวนต์ `"ShopStatusChanged"` ไปไว้ **หลัง** คำสั่งบันทึกฐานข้อมูลสำเร็จ (`DB.CommitChangesAsync`) เพื่อป้องกันความสับสนของสถานะ (Data Inconsistency) ในระบบ

### Admin Dashboard (Angular 19)

* **SignalR Connectivity & Streams:** 
  * ปรับปรุง [tracking-signalr.service.ts](file:///c:/Users/ASUS/Desktop/Project/Delivery/admin-dashboard/src/app/core/services/tracking-signalr.service.ts) เพื่อเพิ่มและสตรีมสถานะเน็ตเวิร์กการเชื่อมต่อ SignalR `connectionStatus$` และช่องทางการสื่อสารเรียลไทม์ของการเปลี่ยนสถานะร้านค้า `shopStatusChanged$`
  * ลงทะเบียนสถานะผ่าน lifecycle callbacks (`start()`, `onreconnecting()`, `onreconnected()`, `onclose()`)
* **GC Spikes Prevention (In-place Mutation):**
  * ปรับปรุงหน้าจอไรเดอร์ [riders.component.ts](file:///c:/Users/ASUS/Desktop/Project/Delivery/admin-dashboard/src/app/features/riders/riders.component.ts) และร้านค้า [shops.component.ts](file:///c:/Users/ASUS/Desktop/Project/Delivery/admin-dashboard/src/app/features/shops/shops.component.ts) โดยยกเลิกการ Clone Array ในสตรีม SignalR และเปลี่ยนเป็นการอัปเดตคุณสมบัติของออบเจ็กต์เดิมในแถวโดยตรง (In-place Mutation) และเรียกใช้ `cdr.markForCheck()` เพื่อรีเฟรชเฉพาะส่วน
  * แก้ไข `idleCount`, `busyCount`, `offlineCount` จาก getters ให้เป็น properties ที่คำนวณใหม่ผ่านเมธอด `recalculateStats()` เมื่อข้อมูลอัปเดต
* **Map Robustness & Sync:**
  * ปรับปรุงแผนที่ [map.component.ts](file:///c:/Users/ASUS/Desktop/Project/Delivery/admin-dashboard/src/app/features/map/map.component.ts) ให้รับฟังเหตุการณ์การเปลี่ยนสถานะร้านค้า `shopStatusChanged$` ใน `ngOnInit` และทำการ Guard ตรวจเช็คความถูกต้องของแผนที่และหมุดพิกัดเพื่อป้องกัน JavaScript Exception หรือ Race Condition ระหว่างการปิด/ทำลายคอมโพเนนต์ (`ngOnDestroy`)
  * ปรับสีหมุดเริ่มต้นและสีหมุดแบบเรียลไทม์ตามสถานะเปิด/ปิดจริงของร้านอาหาร (ส้มเมื่อเปิด / เทาเมื่อปิด)
* **Silent Disconnect Banner:**
  * แสดงแบนเนอร์สีแดง/ส้มเตือนเมื่อสัญญาณ SignalR หลุดหรืออยู่ในช่วง reconnecting ที่แผงด้านบนสุดของหน้าจอไรเดอร์และร้านค้าใน [riders.component.html](file:///c:/Users/ASUS/Desktop/Project/Delivery/admin-dashboard/src/app/features/riders/riders.component.html) และ [shops.component.html](file:///c:/Users/ASUS/Desktop/Project/Delivery/admin-dashboard/src/app/features/shops/shops.component.html)
  * วาดและตกแต่งคอลัมน์สถานะเปิด/ปิด `isOpen` ในหน้ารายชื่อร้านค้า
