# [Dev Team] Changelog: 2026-06-19

## Rider Route Geometry Hybrid Response

- Backend `POST /api/v1/rider-routes/resolve` now returns hybrid road geometry:
  `encodedPolyline` plus OSRM `coordinates` in `[lng, lat]` order.
- `OsrmRoutingService` stores coordinates in the Redis route cache and refreshes
  legacy route cache entries that only contain an encoded polyline.
- Rider Flutter map decodes `encodedPolyline` first, falls back to
  `coordinates` if decode fails, and caches route geometry by `orderId|phase`.
- GPS updates now move the rider marker and trim the route tail only; they do
  not trigger route resolution on every location tick.
- Invalid route geometry retries are cooldown guarded to avoid repeated
  `/rider-routes/resolve` loops.
