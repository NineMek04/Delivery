# 05 — Real Road Test (Driving & Background Test)

## วัตถุประสงค์
ทดสอบการทำงานของระบบบนถนนจริงขณะขับขี่ยานพาหนะ (ความเร็วปกติ 30 – 60 km/h) และทดสอบขณะล็อกหน้าจอโทรศัพท์ (Background Location Service)

---

## ขั้นตอนการทดสอบ

### Phase 1: Slow Vehicle Test (ความเร็วต่ำ 10 – 20 km/h)
1. ขับขี่หรือปั่นจักรยาน/มอเตอร์ไซค์ด้วยความเร็วต่ำ
2. ตรวจสอบค่า `speed`, `heading`, `accuracy` ที่ส่งเข้ามายัง Backend
3. ตรวจสอบการ Snap เส้นทางบน OSRM

### Phase 2: Normal Road Speed Test (ความเร็วปกติ 30 – 60 km/h)
1. ขับขี่ยานพาหนะบนถนนเส้นทางทดสอบจริงในเขตเมืองอุดรธานี
2. สังเกตความถี่ของการส่งพิกัด (GPS Ingestion Rate) และความราบรื่นของเส้นทางบนหน้าจอ Admin Web Map

### Phase 3: Screen-Lock / Background Test (การพับแอปและล็อกหน้าจอ)
1. เริ่มบันทึกเส้นทางในแอป Rider
2. กดปุ่มพาวเวอร์เพื่อ **ล็อกหน้าจอโทรศัพท์ (Lock Screen)** หรือสลับไปใช้แอปอื่น
3. ขับขี่ยานพาหนะต่อเนื่อง 1 – 2 กิโลเมตร
4. ปลดล็อกหน้าจอโทรศัพท์และตรวจสอบ:
   * Foreground Service Notification ยังคงแสดงอยู่ตลอดเวลาหรือไม่
   * พิกัด GPS ขาดช่วงหรือไม่
   * เส้นทางบนแผนที่ครบถ้วนสมบูรณ์หรือไม่
