# 📅 กฎการจัดเก็บผลลัพธ์การทดสอบ (Test Logging Rules)

เมื่อทำการรันชุดทดสอบประสิทธิภาพ (Load & Stress Test) ให้ทำการบันทึกและจัดเก็บไฟล์ในรูปแบบเดียวกันเสมอ:

1. **โครงสร้างโฟลเดอร์:**
   จัดเก็บแยกตามวันที่รันการทดสอบ เช่น:
   `RootScripts\scripts.test\Test_Breaking-Point\LogsTest\YYYY-MM-DD\` (ตัวอย่าง: `2026-06-11`)

2. **การตั้งชื่อไฟล์ผลลัพธ์มาตรฐาน:**
   * `stage5_stats.csv` - ไฟล์ผลลัพธ์ของ Docker Stats (ตัววัด CPU, Mem, Net I/O, PIDs)
   * `stage5_run.log` - ไฟล์บันทึกผลการทำงาน หรือ stdout ของตัวรันคริปต์ทดสอบ (k6 หรือ Node stress script)
   * `stage5_final_report.md` - ไฟล์รายงานวิเคราะห์สรุปผลและรายงานคอขวดระบบ

*ห้ามบันทึกไฟล์ทิ้งไว้ที่รูทโฟลเดอร์ `LogsTest\` โดยเด็ดขาด* เพื่อความเป็นระเบียบและง่ายต่อการวิเคราะห์เปรียบเทียบผลในระยะยาว
